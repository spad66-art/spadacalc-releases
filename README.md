# SpadaCalc pour macOS

Distribution officielle des paquets SpadaCalc signés Developer ID et notarisés par Apple.

Téléchargez le paquet depuis la dernière release. Le manifeste `update.json` de la dernière release est utilisé par SpadaCalc Updater pour vérifier la version, le build, la taille et le SHA-256 du paquet.

Ce dépôt contient uniquement les fichiers publics de distribution, sans code source ni configuration personnelle.
